# Regnvika

Oppgaver og notater om tenkende klasserom i matematikk.

**[Åpne nettsiden](https://andremartiny.github.io/regnvika/)** · 

Endringer som pushes til main blir kontrollert, bygget med Quartz og publisert automatisk til GitHub Pages. Følg publiseringen under Actions → Build and publish Regnvika. Pull requests blir kontrollert og bygget, og publiseres når de slås sammen til main. Det er ikke nødvendig å bygge nettsiden lokalt.

Pages skal ha Settings → Pages → Source satt til GitHub Actions. Den ferdige public-mappen skal ikke committes.

Bygget med [Quartz](https://quartz.jzhao.xyz/). Quartz-lisensen er beholdt i LICENSE.txt.
